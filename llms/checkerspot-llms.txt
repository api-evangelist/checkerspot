# Checkerspot

> Checkerspot is an Alameda, California biotechnology company (founded 2016, a Public
> Benefit Corporation) that designs and produces functional fats and oils through
> precision fermentation of microalgae. Its biology-driven molecule licensing platform
> spans algal strain development, an advanced analytical platform, bioinformatics,
> high-throughput screening, fermentation scale-up and downstream oil refining, built
> around the proprietary microbe Prototheca moriformis. Checkerspot is a
> business-to-business ingredient company, not a software vendor: it publishes no
> public API, no developer portal, no SDK and no machine-readable API contract.

## Platform

- [Our Platform](https://www.checkerspot.com/our-platform/): Six integrated capabilities - algal strain development, advanced analytical platform, bioinformatics, fermentation scale-up, high-throughput screening, and downstream processing and oil refining. The company reports its Prototheca moriformis microbe exceeds 80% oil content by dry cell weight against a 44% average across 150+ comparable organisms.
- [Our Solutions](https://www.checkerspot.com/our-solutions/): Mother's milk fats for infant nutrition, rare fatty acids for health, and designer tropical fat alternatives.

## API surface

- Checkerspot publishes **no public API**. There is no developer portal, no API
  documentation, no OpenAPI/AsyncAPI/GraphQL contract, no MCP server and no A2A agent
  card. Every /.well-known/ path probed returns 404, and api./docs./developer./app.
  subdomains do not resolve. See
  [well-known probe record](https://github.com/api-evangelist/checkerspot/blob/main/well-known/checkerspot-well-known.yml).
- No first-party client library exists on npm, PyPI, RubyGems, crates.io, Packagist or
  NuGet, and there is no github.com/checkerspot organization. See
  [packages](https://github.com/api-evangelist/checkerspot/blob/main/packages/checkerspot-packages.yml).
